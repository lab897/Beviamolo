Beviamolo for Linux

Official Flatpak repository · version @VERSIONE@

Your wine cellar manager: photograph the label and the AI recognises the wine, keep every bottle in its place in your cellar and find the right wine for your dish.

Install Beviamolo

Opens in GNOME Software or KDE Discover. Updates then arrive like any other app.

From the terminal

Install:

flatpak install --user @URL_SITO@/beviamolo.flatpakref

Run and update:

flatpak run dev.lab897.beviamolo
flatpak update

The app uses the GNOME runtime, which Flatpak downloads from Flathub on first install. Packages are signed: the public key is beviamolo.gpg, already included in the install files.

Account

A free Beviamolo account is required. Searching the wine catalogue is free; label recognition and food pairing use AI credits, with a free monthly allowance included. No ads.
